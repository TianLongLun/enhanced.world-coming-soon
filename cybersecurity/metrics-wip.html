Measurement Framework

Essential Cybersecurity Benchmark · Edition Zero
DRAFT v0.1
Methodology brief
For participants & co-creators

ECB measures operational capability under sustained adversarial pressure, not isolated technical skill. Metrics are organized into six functional groups, recorded through server-side telemetry with millisecond UTC timestamps, and validated through a three-tier judge process (LML / ATV / SJ). This document defines the Core set used for Edition Zero — additional research metrics may be enabled per co-creator agreement.

EVIDENCE RULE Attackers must prove successful actions. Defenders must prove detection and response. Judges verify against correlated multi-source telemetry. Unverified claims do not score.
01 Core metric groups A measurements server-side, ms-precision UTC, cross-source correlated

A. Time-to-event raw

Direct timestamped intervals between adversarial actions and operator responses.
  • MTTD — compromise → first detection
  • MTTRd — detection → active interruption
  • MTTRr — full service recovery (≥3 min outage threshold)
  • TTP — scenario start → first foothold
  • TTPE — foothold → privilege escalation
  • Persistence lifetime — mean undetected dwell
  • Service availability — heartbeat probe uptime

B. Outcome & coverage verified

Judge-confirmed results of offensive and defensive activity over the scenario window.
  • Objective completion rate — flags / mission goals
  • Detection coverage — detected / total attacker actions
  • False negative rate — missed actions / total
  • False positive burden — operator-time-cost weighted
  • Containment efficiency — blast radius reduction
  • Recovery completeness — functional restoration verified
  • Lateral movement count — successful pivots

C. Team coordination behavioral

Internal team dynamics derived from comms timestamps, ticket chains, and protocol logs.
  • Coordination latency — event → first internal response
  • Escalation integrity — correct routing rate
  • Protocol adherence — declared playbook vs executed
  • Decision chain length — steps to action
  • Role overlap rate — duplicated work indicator
  • Shift transition quality — handover degradation cost
  • Cross-team interaction — Blue/Red engagement quality

D. Human–AI workflow unique

Operator-AI collaboration recorded via prompt logs, override events, and outcome correlation.
  • AI response latency — request → actionable output
  • AI actionability ratio — used / generated outputs
  • Human override rate — rejected AI suggestions
  • Prompt iteration depth — attempts to usable answer
  • Hallucination impact — operational cost of bad AI output
  • Trust calibration — acceptance × correctness
  • Cloud vs local-AI delta — performance differential

E. Longitudinal degradation unique

Performance change across the 84h adversarial window — only observable in sustained format.
  • Performance decay curve — skill metric vs elapsed time
  • Error acceleration — mistake rate growth
  • Reaction-time drift — MTTD trend across shifts
  • Detection-rate decay — SOC weakening over time
  • Recovery adaptation — learning curve, repeat incidents
  • Comms collapse rate — team fragmentation indicator

F. Infrastructure load raw

System-level state during operations — required for fair normalisation across teams.
  • CPU / RAM pressure — per-host utilisation
  • Network saturation — interface throughput & loss
  • Telemetry throughput — ingestion vs capacity
  • Log delay — SIEM lag
  • Tool stability — security stack crash/restart events
  • Storage latency — evidence pipeline health

03 Measurements not obtainable from existing sources Why this dataset has no public substitute

Methodology integrity. Weights, formulas, and thresholds are versioned and frozen before each edition. Confidence levels are recorded per metric. The framework distinguishes raw, derived, and composite measurements explicitly to support replication and independent re-analysis. Optional research extensions (cognitive load, attention, biometrics) are opt-in, consent-based, and not part of the Core ranking.
